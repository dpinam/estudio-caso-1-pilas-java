# Analizador de expresiones aritméticas con pilas (Java)

Estudio de caso 1 – Estructuras de Datos (SOFT-10), Universidad CENFOTEC.

Pila enlazada de tokens (`Token`, `Nodo`, `PilaTokens`) aplicada al análisis de expresiones
aritméticas: validación de paréntesis y sintaxis, conversión infija a postfija (shunting-yard)
y evaluación, con un menú interactivo en `Main`.

## Compilar y ejecutar

    javac -d out *.java
    java -cp out Main
